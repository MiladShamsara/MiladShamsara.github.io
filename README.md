# Milad Shamsara — Industrial Executive Portfolio

Bilingual Persian/English portfolio built with static HTML and CSS for GitHub Pages.

- Persian homepage: `index.html`
- English homepage: `en/index.html`
- Shared stylesheet: `assets/style.css`
- Existing CV PDFs and contact card remain in `assets/`.

## Publish
Upload the contents of this folder to the root of `MiladShamsara.github.io` and commit to the publishing branch configured in GitHub Pages. No build step is required.
